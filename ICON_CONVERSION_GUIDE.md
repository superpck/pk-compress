# Icon Conversion Guide

## Option 1: Online Converter (แนะนำ - ง่ายที่สุด)

1. เปิดไฟล์ [icon.svg](icon.svg) ในโปรเจกต์
2. ไปที่ https://cloudconvert.com/svg-to-png
3. Upload icon.svg
4. Convert เป็น PNG ขนาดต่างๆ:
   - 512x512 (สำหรับ macOS, Windows)
   - 256x256
   - 128x128
   - 32x32
5. บันทึกไฟล์ PNG ลงในโฟลเดอร์ `src-tauri/icons/`

## Option 2: Using ImageMagick (macOS)

```bash
# Install ImageMagick
brew install imagemagick

# Convert SVG to multiple PNG sizes
convert -background none -density 1024 icon.svg -resize 512x512 src-tauri/icons/icon.png
convert -background none -density 1024 icon.svg -resize 256x256 src-tauri/icons/icon@2x.png
convert -background none -density 1024 icon.svg -resize 128x128 src-tauri/icons/128x128.png
convert -background none -density 1024 icon.svg -resize 32x32 src-tauri/icons/32x32.png
```

## Option 3: Using Inkscape (Cross-platform)

```bash
# Install Inkscape
brew install --cask inkscape  # macOS
# or download from https://inkscape.org/

# Convert using command line
inkscape icon.svg --export-filename=src-tauri/icons/icon.png --export-width=512 --export-height=512
inkscape icon.svg --export-filename=src-tauri/icons/128x128.png --export-width=128 --export-height=128
inkscape icon.svg --export-filename=src-tauri/icons/32x32.png --export-width=32 --export-height=32
```

## Option 4: Using GIMP (Cross-platform GUI)

1. Install GIMP: https://www.gimp.org/downloads/
2. Open icon.svg in GIMP
3. Export as PNG with desired size
4. Save to `src-tauri/icons/`

## Required Icon Sizes for Tauri

Create these files in `src-tauri/icons/`:

- `icon.png` (512x512) - Main icon
- `icon.icns` (macOS) - Will be generated by Tauri
- `icon.ico` (Windows) - Will be generated by Tauri
- `32x32.png` (32x32) - Small icon
- `128x128.png` (128x128) - Medium icon
- `128x128@2x.png` (256x256) - Retina display
- `icon.icns` - macOS icon bundle

## Auto-generate with Tauri CLI

Tauri can auto-generate icon formats:

```bash
# Install Tauri CLI if not already installed
cargo install tauri-cli --version "^2.0"

# Generate all icon formats from source PNG
cd src-tauri
tauri icon path/to/icon.png

# This will create all required formats automatically
```
